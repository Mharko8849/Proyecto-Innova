### Descripción general del proyecto

ÍndicePartidas es una plataforma orientada a pequeñas y medianas empresas, contratistas y trabajadores independientes que elaboran cotizaciones y necesitan controlar de mejor manera la diferencia entre lo presupuestado y el costo real de los trabajos ejecutados.

El sistema contará inicialmente con tres rubros predefinidos: **Construcción, Electricidad y Vidriería**, cada uno con su respectivo catálogo de partidas, materiales, mano de obra, rendimientos, unidades de medida y precios de referencia. A partir de estos elementos, el usuario podrá elaborar cotizaciones, configurar márgenes y gastos generales, generar diferentes versiones de un presupuesto y convertir una cotización aceptada en una Orden de Trabajo.

Durante la ejecución del trabajo, el sistema permitirá registrar de forma simple las cantidades realmente utilizadas, materiales consumidos, horas de trabajo, costos adicionales, avances e incidencias. Una vez finalizada la Orden de Trabajo, la plataforma comparará automáticamente los valores cotizados con los costos reales ejecutados, permitiendo identificar desviaciones, conocer la rentabilidad obtenida y utilizar esa información como referencia para futuras cotizaciones.

Además de los tres rubros predefinidos, la plataforma contará con una opción **“Otro”**, destinada a usuarios pertenecientes a actividades diferentes. En este caso, el usuario podrá crear y nombrar su propio rubro, definir los conceptos que utiliza para cotizar, sus unidades, variables, fórmulas, costos y parámetros de cálculo. Esta configuración quedará almacenada para ser reutilizada en futuras cotizaciones, permitiendo que la plataforma se adapte progresivamente a distintos tipos de pequeñas empresas y servicios.

La información histórica generada mediante las cotizaciones y trabajos ejecutados permitirá construir el **ÍndicePartidas**, compuesto por datos agregados y anonimizados de costos y rendimientos reales. Este índice podrá servir como referencia para contratistas y, posteriormente, para otros actores como mandantes, tasadores, aseguradoras o inmobiliarias, sin exponer información comercial sensible, márgenes individuales ni la identidad de las empresas que aportan los datos.

De esta forma, el propósito de ÍndicePartidas no es solamente facilitar la creación de cotizaciones, sino también cerrar el ciclo entre **presupuestar, ejecutar, comparar y aprender**, utilizando la información histórica para reducir errores de estimación, mejorar futuras decisiones de precio y generar conocimiento sobre los costos reales de ejecución.
